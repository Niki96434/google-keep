# Pig Keep
MVP веб-приложение с виртуальным питомцем, основной продукт которого - приложение заметок. За выполненные задания пользователь получает награды в виде XP, повышает уровень питомца и вместе с тем помогает ему расти. 
## Сценарий
1.Пользователь регистрируется в приложении, используя почту/логин и пароль.
2.Ежедневно выдаются задания, за каждое выполненное задание пользователь получает +10XP и 3 HP для питомца.
3.Если пользователь активно использует приложение, то у него есть возможность попасть в лидерборд.
4.Если пользователь совсем не использует приложение заметок(основной продукт),то пользователь теряет свой прогресс, в том числе питомец умирает.

## Перечень используемых технологий (с их обоснованием)

- React 19, Typescript, Vite, Eslint, Prettier, Vitest, RTL, RTQuery, Zod
- Express.js, Supertest, Drizzle ORM
- PostgreSQL 18

## Структура проекта

- apps/frontend/src - React-приложение
- apps/backend/core - Инициализация базы данных, глобальный обработчик ошибок, мидлвары
- apps/backend/features - feature-based модульная архитектура
- apps/backend/migrations - схемы PostgreSQL
- apps/packages/shared - общие типы и схемы контракта
- apps/docs - таблица с описанием эндпоинтов(REST), диаграммы компонентов и развёртывания, дизайн мобильного интерфейса, на планшете и десктоп
